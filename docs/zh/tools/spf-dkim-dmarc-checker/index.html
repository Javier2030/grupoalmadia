发票诈骗

冒用您的邮箱，并不需要您的密码。

电子邮件在设计之初并不核实发件人的身份。任何服务器都可以声称“这封邮件来自 manager@yourcompany.com”。唯一能阻止这种行为的，是您在域名上发布的三条记录。如果缺失或配置不完整，伪造的邮件就可能送达。

01

骗子选定要联系的对象

您的客户、会计、银行或内部付款团队。这些人的名字通常能在您的网站和社交媒体上找到。

02

用您的确切地址发出邮件

不是相似的域名，而是您自己的域名。内容可能是更换了银行账户的发票、“付款信息变更”通知，或是经理发出的紧急指令。

03

收件方的服务器查询您的域名

它会询问该发件人是否获得授权，以及未获授权时应如何处理。如果您的域名没有任何回应，邮件就可能被正常投递。

04

客户付了款，回头向您追问

钱转入了另一个账户，而在所有人看来，这封邮件就是从您的公司发出的。商业纠纷和法律问题由此开始。

工具检查哪些内容

三条记录决定您的邮件能否被伪造。

这三条记录都发布在您域名的 DNS 中，并且是公开的：任何邮件服务器在接收邮件之前都会读取它们。本工具执行同样的读取，并把结果翻译成您能看懂的语言。

记录作用缺失或配置错误会怎样我们检查什么
SPF列出可以使用您的域名发送邮件的服务器。没有任何服务器知道您的邮件应该从哪里发出。如果存在多条记录、需要超过 10 次 DNS 查询，或引用了不存在的服务，该记录会被判定为无效。记录是否存在且只有一条、结尾如何设置（拒绝、标记或放行）、需要多少次 DNS 查询，以及所引用的服务是否有效。
DKIM为每封邮件附上数字签名，并用发布在您域名中的公钥进行验证。您的邮件只能依赖 SPF，而邮件被转发时 SPF 就会失效。是否发布了使用服务商常用名称的密钥、密钥是否处于启用状态，以及密钥的长度。
DMARC一条指令：当邮件使用了您的域名，却未能以该域名的名义通过 SPF 或 DKIM 验证时，应当如何处理。没有 DMARC，或 DMARC 设置为“p=none”，伪造的邮件就可能进入收件箱。它是起决定作用的记录。记录是否存在且只有一条、策略类型（仅监控、隔离或拒绝）、是否处于测试模式或仅适用于部分邮件、子域名如何处理，以及是否要求发送报告。
附加防护层DNSSEC、MTA-STS、TLS-RPT、CAA 和 BIMI。它们不会直接为冒充邮件打开方便之门，但却是“合格的域名”与“管理周到的域名”之间的差别。是否已发布。它们在评分中占比较小，重要性排在前面几项之后。

0 到 100 分的评分按以下权重计算：DMARC 占 45，SPF 占 25，DKIM 占 15，附加防护层占 15。风险结论主要取决于 DMARC，因为在这三项中只有它能要求拦截伪造邮件。

如何看懂结果

各个风险等级的含义。

高风险

  • 您的域名没有 DMARC，或 DMARC 处于监控模式（“p=none”）。
  • 目前，使用您地址的伪造邮件可能进入收件箱。
  • 这是小型企业中最常见的情况，无需更换邮件服务商即可修复。

中等或低风险

  • 中等：已有生效的策略（隔离），但仍有漏洞：策略只适用于部分邮件或处于测试模式，子域名未被覆盖，或者 SPF 允许任何人发送。
  • 低：您的域名要求拒绝伪造邮件。接下来只需确认所有发信服务都已签名，并查看报告。
  • 无论哪种情况，详细结果都会按重要程度从高到低告诉您需要改进什么。
为什么现在很重要

这已不再是可选项：大型邮箱服务商都有硬性要求。

  • Google（自 2024 年 2 月起）：要求每天向 Gmail 账户发送超过 5,000 封邮件的发件人配置 SPF、DKIM 和 DMARC，其他所有发件人至少要配置 SPF 或 DKIM。Yahoo 对群发邮件的发件人也实行相同的规定。
  • Microsoft（自 2025 年 5 月起）：要求每天向 Outlook、Hotmail 和 Live 发送超过 5,000 封邮件的域名配置 SPF、DKIM 和 DMARC。
  • 送达率：没有这些记录的域名不仅容易被冒充，其合法邮件，包括发票和报价单，也更容易被归入垃圾邮件。
  • 数据保护：没有任何法律明确提到 DMARC，但欧洲的 GDPR（第 32 条）或哥伦比亚的第 1581 号法律（2012 年）等规范，要求处理个人数据的机构采取适当的技术措施，防止未经授权或欺诈性的使用。可被冒充的企业邮箱显然是一个薄弱环节。
  • 追究骗子的责任是可行的，但过程缓慢。以哥伦比亚为例，第 1273 号法律（2009 年）对冒用网站窃取数据以及未经同意转移资产的行为予以惩处。而堵住这扇门只需要几周时间。
坦率地说

本次检测无法告诉您的事。

  • 不检查邮箱和密码。如果团队中有人的密码被盗，邮件确实是从您的账户发出的，任何 DNS 记录都无法阻止。这需要通过双重验证来解决。
  • 无法发现相似域名。骗子可以注册 yourcompany-payments.com 这样的域名。DMARC 保护的是您自己的域名，而不是与之相似的域名。
  • DKIM 的结果并非定论。密钥无法从外部列出；如果您的密钥名称不常见，就不会被发现。
  • 这不是渗透测试，也不是经过认证的审计。它只是读取您域名的公开配置，而大多数邮件诈骗正是从这里开始的。
  • 评分高并不保证邮件一定送达。邮件服务商还会参考发件人的信誉和邮件内容。
常见问题

关于邮件被冒充，大家常问的问题。

邮件被冒充是什么意思？

是指有人在“发件人”栏中使用您的确切地址（例如 billing@yourcompany.com）发送邮件，却从未进入过您的邮箱。他们不需要您的密码：只要您的域名没有告诉邮件服务器拒绝那些并非来自您的邮件，他们就能做到。他们会借这类伪造邮件索要付款、更改发票上的账号，或窃取密码。

我怎么知道自己的域名是否受到保护？

请在本页的检测工具中输入域名。几秒钟内，它会告诉您域名是否已发布 SPF、DKIM 和 DMARC，更重要的是，DMARC 策略是真正拦截伪造邮件，还是仅仅在监控。如果结果显示“高风险”，现在就有人可以冒用您的名义发送邮件。

SPF、DKIM 和 DMARC 有什么区别？

SPF 是获准使用您的域名发送邮件的服务器清单。DKIM 是一种数字签名，用来证明邮件确实来自您的某项服务，并且没有被篡改。DMARC 把两者结合起来并下达指令：当邮件使用了您的域名，却没有以该域名的名义通过这两项验证时，应当如何处理（放行、转入垃圾邮件或直接拒绝）。没有 DMARC，另外两项并不能阻止冒充。

我的 DMARC 是“p=none”，这样安全吗？

不安全。“p=none”是监控模式：您的域名不要求对伪造邮件采取任何措施，这些邮件照样可能送达。如果记录中设置了报告，您会收到有关谁在以您的名义发邮件的详细信息。这是正确的第一步，之后应分阶段升级到隔离，再升级到拒绝，前提是报告确认您的合法邮件都能通过验证。

为什么不直接设置“p=reject”？

因为如果您的某项合法服务（电子发票、订阅通讯、CRM、网站表单）以您的名义发信，但配置不当，您自己的邮件就会被拒收。因此需要分阶段进行，每次调整之前先查看报告。

这个工具会保存我的域名或数据吗？

不会。检测在您的浏览器中运行：查询直接发送到 Google 和 Cloudflare 的公共 DNS 解析服务，它们会像处理任何 DNS 查询一样收到域名。Almadía 不会接收您输入的域名，不要求提供邮箱或注册，页面也没有任何统计分析。只有当您决定通过 WhatsApp 联系我们时，我们才会知道。

这是渗透测试吗？

不是。该工具只读取 DNS 记录，而这些记录在设计上就是公开的：任何邮件服务器在接收邮件前都会查询同样的信息。它不会接触您的系统，不会尝试密码，也不会发送任何邮件。因此，您也可以用它检查供应商或客户的域名。

我的邮箱是 @gmail.com 或 @hotmail.com，可以用吗？

本检测适用于自有域名（例如 yourname.com、yourcompany.com）。如果您使用的是免费邮箱，防冒充的保护由服务商负责管理，您无法自行更改。对企业来说，使用自有域名并正确配置邮箱，是第一步。

我明明配置了 DKIM，为什么显示没有找到？

DKIM 密钥无法从外部列出：它们以服务商自行选定的名称（“选择器”）发布。工具会尝试最常用的名称；如果您的名称不同，就不会被发现。如果您知道选择器，请填写在可选的选择器栏中。您也可以查看从您的域名发出的一封真实邮件的邮件头来确认。

Google 和 Microsoft 有这方面的要求吗？

有，针对大批量发件人。自 2024 年 2 月起，Google 要求每天向 Gmail 发送超过 5,000 封邮件的发件人配置 SPF、DKIM 和 DMARC，Yahoo 对群发邮件的发件人也有同等规定。自 2025 年 5 月起，Microsoft 对每天向 Outlook、Hotmail 和 Live 发送超过 5,000 封邮件的发件人提出同样的要求。对于小型发件人，Google 至少要求配置 SPF 或 DKIM。实际上，没有这些记录的域名，越来越容易被归入垃圾邮件。

修复需要多少费用？

检测是免费的。邮件修复（配置并测试 SPF、DKIM 和 DMARC，并分阶段升级到拒绝）已包含在中小企业防护套餐中，该套餐有公开标价。如果您只需要处理邮件，请把域名发给我们，我们会在开始前以书面形式给您一个固定报价。

你们在哪些国家提供服务？

任何国家。我们远程提供服务：您可以给我们开放域名的 DNS 管理面板的权限，或者按我们的指引自行修改，我们通过 WhatsApp、电子邮件或视频通话沟通。工具和服务支持 13 种语言。
